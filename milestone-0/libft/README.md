# Libft

## Description
<!-- Clearly present the project, including its goal and a brief overview. -->
Libft is the very first project in the 42 Common Core curriculum. The goal is to recreate a set of standard C library (`libc`) functions, as well as other utility functions that will be useful throughout the cursus. This project serves as a foundation for future C projects by deepening the understanding of memory allocation, string manipulation, pointer arithmetic, and linked lists. The result is a static library, `libft.a`, which can be linked with other programs.



### Compilation
The project includes a `Makefile` which compiles the source files with the flags `-Wall -Wextra -Werror` and creates the static library `libft.a` at the root of the repository.

To compile the mandatory part of the library:
```bash
make
